## نتائج التحقق

- نجح أمر اختبارات المشروع داخل Linux Docker باستخدام الاعتماديات الموجودة محليًا؛ أضيفت حالات انحدار في ops-import، report-settings، prometric-credentials، وحالة تنظيف النوافذ في cloud.test.
- نجح تجهيز أصول Next والامتداد، ونجح `tsc --noEmit --incremental false`. أُعيد الاختبار الخاص بالتقارير وفحص الأنواع بعد آخر تبسيط للكود.
- نجح اختبار `tests/worksheet-quota-database.sql` بعد تطبيق المخطط والترحيلات على PostgreSQL معزول بهويات وهمية. نجح فحص تزامن منفصل لاتصالين؛ حُذفت الحاوية بعدها.
- نجح `git diff --check` وفحص صياغة JavaScript المعدل.
- فشل بناء Next الإنتاجي الكامل قبل ترجمة التطبيق: حزمة SWC الخاصة بـLinux غير موجودة في تثبيت Windows المحلي، ولم يُسمح بتنزيلها من الشبكة. هذه ليست نتيجة بناء ناجح، ويظل البناء الكامل وفحص المتصفح مطلوبين قبل النشر.

عمليات التنفيذ كانت بدون شبكة وببيئة متغيرات صريحة، مع المصدر والأدوات للقراءة فقط والكتابة في tmpfs خاص بالحاوية وحدود للذاكرة والمعالج والعمليات والوقت. لم تُشغّل اختبارات على الإنتاج، ولم تُستخدم بيانات أو حسابات حقيقية. الملف غير المتتبع trainees-dashboard-preview.html محفوظ كما كان.

## تفعيل التغييرات

1. راجع وطبّق `supabase/migrations/20261014090000_enforce_worksheet_quota.sql` بعد ترحيلات الأوراق الحالية على البيئة المقصودة. الإصلاح يظل غير فعال في قاعدة البيانات المنشورة إلى أن يُطبّق الترحيل. السجلات الموجودة محفوظة؛ لا يحذف الترحيل أوراقًا زائدة موجودة مسبقًا.
2. ابنِ التطبيق في بيئة بها SWC المناسب ثم نفّذ فحوص المتصفح المعتادة قبل النشر.
3. حدّث ملفات امتداد Prometric وأعد تحميل نسخته 4.2.6. الإعداد الافتراضي العشوائي يخص التسجيلات الجديدة؛ لا يغير كلمات مرور حسابات موجودة. القوالب المخصصة الصريحة بقيت متاحة.

لا توجد دعوى بقبول مزوّد Prometric للنسق الجديد أو اكتمال تسجيل حي؛ لم تُجرَ إجراءات على المزوّد. لا يقدم [دليل TCNet الرسمي](https://media.prime.prometric.com/files/ibt_pdf/TCNet%20Candidate%20User%20Guide.pdf) الذي راجعناه حدًا عدديًا لطول كلمة المرور؛ قبول سياسة البرنامج الفعلية يحتاج تحققًا مأذونًا قبل تعميم التسجيلات.

لم تُغيّر سياسة الموعد اليومي لمسار REST المباشر، إذ يستثنيه التوثيق الحالي صراحة. فجوتا مراجعة نصوص نوافذ الامتداد ودورة صلاحية المهام بعد الخروج تحتاجان جولة أمان مستقلة؛ لا تُعدّان ثغرات مؤكدة أو إصلاحات مكتملة في هذه الجولة.
